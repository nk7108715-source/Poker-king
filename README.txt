POKAR KING — Starter Prototype
==============================

Included:
- index.html: single-file responsive Texas Hold'em-style practice prototype.
- No build tools or paid software needed.
- Runs locally in a modern mobile browser.

How to test on Android:
1. Download and extract PokarKing_Starter.zip using your phone's Files app.
2. Open index.html with a code editor that supports preview, or upload it to a private/public test repository and enable static hosting.
3. Tap “Deal hand” and test the action buttons.

Important limitations:
- This is a LOCAL DEMO, not online multiplayer.
- Opponents are simulated bots. Do not treat this as production poker logic.
- Hand evaluation and betting are simplified starter logic and need a full rules-engine test pass before real play.
- The demo uses virtual chips only and has no cash deposits, withdrawals, or real-money betting.
- Next development step: improve poker rules and create a secure server-authoritative multiplayer backend with room synchronization.
